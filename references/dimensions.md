# 判断维度(第二阶段,待与小霖确认)

来源:2026-09-15 录音。每条结论先行、一句话;结论之后逐条给一段推导,每条带盘面依据。不出分数、不出置信度。

| 维度 | 输出形态 |
|---|---|
| 性格 | 三条,每条一句 |
| 学历 | 一个范围 |
| 家庭 | 父母婚姻感情大概;父母职业范围 |
| 感情 | 递进分支:先按年龄判到没到婚龄 → 未到:恋爱时间、感情变动时间 → 到了:是否已婚、结婚时间、生育时间与性别 → 婚姻有问题再判:是否离婚、离婚时间 |
| 工作 | 职业类型、所在行业 |
| 健康 | 哪个方面可能有问题 |
| 外貌 | 体型与外貌大概 |

红线:不为未成年人做婚育与健康推断。

## 断语示例(合格 / 不合格)

| 维度 | 不合格(免责、两可) | 合格(一条一个答案) |
|---|---|---|
| 学历 | 先猜本科至硕士范围,实际学历无法由命盘确定 | 本科,理工或经管类 |
| 父母关系 | 有牵连也有摩擦,不能据此断父母离异 | 父母未离,但常年关系冷淡,父亲在家庭里存在感弱 |
| 感情 | 盘面不能确认是否已婚;2026–2027 列作观察窗口 | 未婚;2024 年起有稳定恋爱;2027 年前后结婚;2029 年前后得一女 |
| 健康 | 命盘不能判断具体健康问题 | 脾胃偏弱,易消化不良;30 岁后留意血压 |
| 外貌 | 只保留一个粗略假设,等待反馈 | 身高中等偏高,偏瘦,脸偏长,颧骨略明显 |

推导块每条只解释「为什么是这个答案」,不再重复免责。
